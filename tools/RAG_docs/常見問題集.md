# 資訊管理系 常見問題集 (FAQ)

## 學籍相關問題

### Q1: 如何申請成績單？
**A:** 可透過以下方式申請：
1. 線上申請：登入學校資訊系統，點選「成績單申請」
2. 臨櫃申請：至註冊組填寫申請表
3. 處理時間：線上申請 1-2 工作日，臨櫃申請當日取件

### Q2: 如何辦理休學？
**A:** 休學申請程序：
1. 下載休學申請表（學校官網下載）
2. 填寫申請表並取得家長同意書
3. 繳交至系辦公室初審
4. 系主任簽核後送註冊組
5. 注意：每學期休學申請截止日期為期中考後兩週

### Q3: 轉系申請條件？
**A:** 轉系申請資格：
- 大一下學期結束後始可申請
- 學業成績排名前 50%
- 操行成績 B 以上
- 申請時間：每年 6 月及 12 月

## 課程相關問題

### Q4: 如何加退選課程？
**A:** 加退選流程：
1. **加退選時間**：每學期開學後兩週內
2. **線上操作**：登入選課系統進行加退選
3. **人工處理**：特殊情況可至系辦公室申請
4. **注意事項**：必修課不可退選，選修課有人數限制

### Q5: 課程衝堂怎麼辦？
**A:** 課程衝堂處理方式：
- 必修課優先，選修課次之
- 高年級課程優先於低年級課程
- 可申請課程時間調整（需經授課教師同意）
- 嚴重衝堂可申請專案處理

### Q6: 如何申請學分抵免？
**A:** 學分抵免申請：
1. 準備原校成績單正本
2. 提供課程大綱或教學計畫
3. 填寫學分抵免申請表
4. 經系主任及教務處核准
5. 申請時間：每學期開學前兩週

## 實習與就業問題

### Q7: 實習課程如何安排？
**A:** 實習課程規劃：
- **時間**：大四上學期或下學期
- **學分**：3-6 學分
- **申請**：需提前一學期申請
- **合作企業**：系上有配合企業名單
- **評量**：實習報告 + 企業評量

### Q8: 如何準備就業？
**A:** 就業準備建議：
1. **技能培養**：程式設計、資料分析、專案管理
2. **證照考取**：Microsoft、Oracle、Cisco 等認證
3. **實習經驗**：積極參與企業實習
4. **作品集**：建立個人專案作品集
5. **履歷撰寫**：參加履歷撰寫工作坊

## 設備與服務問題

### Q9: 如何借用電腦教室？
**A:** 電腦教室借用流程：
1. 填寫教室借用申請表
2. 說明使用目的與時間
3. 經系辦公室核准
4. 借用時間：週一至週五 8:00-17:00
5. 假日借用需特別申請

### Q10: 網路帳號密碼忘記怎麼辦？
**A:** 帳號密碼處理：
- **學號帳號**：至計算機中心重設密碼
- **Email 帳號**：線上申請重設或臨櫃辦理
- **選課系統**：使用學號及身分證後四碼登入
- **緊急聯絡**：計算機中心 07-3814526 轉 31

## 獎學金與補助

### Q11: 有哪些獎學金可以申請？
**A:** 獎學金種類：
1. **學業優秀獎學金**：每學期成績前 10%
2. **清寒助學金**：家境困難學生
3. **研究獎助金**：研究所學生專用
4. **企業獎學金**：產學合作企業提供
5. **申請時間**：每學期開學後一個月內

### Q12: 如何申請工讀機會？
**A:** 工讀申請方式：
- **系內工讀**：協助行政業務、教學支援
- **校內工讀**：圖書館、計算機中心等單位
- **建教合作**：企業提供之工讀機會
- **申請資格**：在學學生，成績及操行良好
